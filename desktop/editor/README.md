# TFM2 Atlas Editor 1.0.33

Player, staff, contract, transfer, economy, mastery and persistent-lock editing for Teamfight Manager 2 `0.5.5`.

Required game mods:

- `tfm2_atlas_core`
- `tfm2_atlas_client_055`
- `tfm2_atlas_editor`

`TFM2.Atlas.Editor.exe` is a separate portable application with its own settings and bridge connection.

Author: ehcho

Inspired by TFM2 Editor by jal-io — https://github.com/jal-io/tfm2-editor

The current Stable ABI service and Electron interface are independent implementations. See `UPSTREAM_NOTICE.md` for the provenance boundary. Atlas-authored material is distributed under `LICENSE-ATLAS.txt` in the release package.
