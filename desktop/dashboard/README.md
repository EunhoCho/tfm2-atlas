# TFM2 Atlas Dashboard 1.0.33

Career statistics, champion tiers, champion information and manual Draft analysis for Teamfight Manager 2 `0.5.5`.

Required game mods:

- `tfm2_atlas_core`
- `tfm2_atlas_client_055`

`TFM2.Atlas.Dashboard.exe` is portable and does not require Atlas Editor.
